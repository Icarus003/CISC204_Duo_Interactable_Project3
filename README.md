# CISC204 - Pair Project: Interactables

About:
This project is from CISC204 (Intro to Game Dev). The project is a pair project (With my classmate Dawson) where we were assigned to make a game that has 4 rooms (1 main room, 2 side rooms, and a final room that unlocks from interactables) and has 4 interactables. In this game out interactables were (1) a collectable orb that gets tallied in a global script, (2) levers that get pulled to open doors, (3) tombs that open via an input, and (4) text boxes that activate via input. 

My Contribution:
- I created teh tilesheets and all the assets (minus the grass tiles, the ghost, and skeletons)
- Added in collisions and player script
- Did the level design and about half of the ingame text 
- Did the tomb opening interactable 
- Did the coding for the orb collection to unlock final room

What I learned:
- How to use and create interactables 
- How to use global scripts 
- How to go between scenes in Godot 
- Delegating work between a pair of two people to play into each persons strengths 
- Learned how to use github with other people
